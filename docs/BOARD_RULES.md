## Board Completion & Advancement
- A board unit is marked `COMPLETED` when all 7 positions are occupied.
- Top position receives the Board Completion Reward (funded from `reserveForBoardRewards`).
- If direct sponsor threshold is satisfied, Top position advances to Board Level $N+1$.
- Upon completing Board 5, a permanent on-chain `CycleRecord` is logged.
