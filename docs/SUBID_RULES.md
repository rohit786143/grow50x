# SUB-ID SYSTEM & AUTOMATIC BATCH GENERATION

## Sub-ID Ownership
- Sub-IDs can ONLY be created by the wallet owning the Main User ID.
- Unrelated external wallets cannot create or control another user's Sub-IDs.

## Manual Sub-ID Sponsor Restrictions
For manual Sub-ID creation, the permitted sponsor dropdown is strictly restricted to IDs owned by the caller:
$$\text{Permitted Sponsors} = \{\text{Main ID}, \text{Sub-ID}_1, \dots, \text{Sub-ID}_{N-1}\}$$

## Automatic 20-Sub-ID Batch Engine
- Batch quantity $K \in [1, 20]$. Total Cost = $K \times 100$ USDT.
- **Deterministic Breadth-First Binary Sponsor Tree**:
  - Sub 1 & Sub 2 $\rightarrow$ Sponsored by Main ID
  - Sub 3 & Sub 4 $\rightarrow$ Sponsored by Sub 1
  - Sub 5 & Sub 6 $\rightarrow$ Sponsored by Sub 2
- **Sub-ID Level Income Consolidation**: Level income (3% L1, 2% L2, 1% L3) generated by Sub-IDs is paid directly to the Main User wallet of the qualifying sponsor ID.
